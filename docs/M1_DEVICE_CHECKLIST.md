# M1 — iPhone / iPad Safari 驗收

在 Safari 直接開啟私密測試網址並完成登入；不要只在內嵌預覽操作。準備 A4 白紙、平整桌面與手機支架。這個版本只驗證 camera + paper registration，沒有 reference import / save / PWA。

記錄：裝置型號、iOS/iPadOS 版本、Safari/主畫面模式、日期，以及每項 PASS / FAIL。最好先測 iPhone，再測 iPad。

1. 模擬畫紙：依 A 左上 → B 右上 → C 右下 → D 左下點選四角。確認後，網格外框應與畫紙四邊重合。
2. 切換模擬角度：原校準清除；重新指定四角，網格仍應貼合新的紙張透視。
3. 無效順序：交叉選角應出現提示，不能確認。撤回一角並重選可恢復。
4. 後鏡頭：按開啟並授權。應看見鏡頭外的桌面，而不是自拍；畫面持續更新，沒有跳到純 video 全螢幕。
5. 實紙：選正確紙張設定；固定裝置且四角可見。選角並拖動微調；確認外框貼齊紙邊。
6. 斜角：調整固定支架的角度，手動重新校準；網格能貼合斜角紙面。M1 不會自動追蹤移動。
7. 休眠/切 App：返回後不得顯示舊校準為有效；相機應能重新開啟並完成校準。
8. 旋轉裝置：校準失效，有重選提示；新預覽的選角與網格仍對齊。影像黑色留白不能選成紙角。
9. 權限拒絕：顯示可理解的提示，模擬畫紙仍能操作。之後在 Safari 設定允許相機，可重試。
10. 專注畫面與觸控：按鈕未被安全區遮住，A–D 可用手指微調，工具區可捲動；返回工作室有效。

M1 通過條件：兩台目標裝置可開 camera、四角選取/微調與透視網格正常，並能從離開頁面後重啟。沒有 iPad 時可先記為 NOT TESTED，不能宣稱 iPad 通過。
