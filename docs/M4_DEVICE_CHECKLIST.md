# M4 — PWA 與 iPhone/iPad 驗收

狀態：manifest、icons、service worker、focus、optional fullscreen/wake lock 已實作；實機 **NOT TESTED**。私密 Sites 登入與離線相容性未由本環境確認。

## 主畫面與離線

1. iPhone Safari 直接開私密測試網址，登入自己的 ChatGPT 帳號。
2. 展開「加入主畫面與離線使用」，等待「離線 App 已準備好」。若失敗，記錄實際提示與 Console/Network（可使用 Mac Safari 遠端檢查）。
3. 分享 → 加入主畫面，從 Paper 圖示開啟；確認圖示、名稱、standalone 版面、安全區域，先保持連線再等待離線就緒。
4. 若 Safari 保存的作品未出現在主畫面，用原瀏覽器匯出，再到主畫面匯入。不要假設儲存共享。
5. 保存測試作品，確認完成，關閉 App；開飛航模式，再從主畫面啟動。應顯示 App 與本機作品，而非登入頁或空白。
6. 恢復作品、開相機、重新校準；測試照片匯入、透視與操作。
7. 回到線上。App 若提示新版本，未保存時更新應被阻止；保存後按更新，Session 必須還在。
8. 登出／登入過期／重新登入的線上流程不得被快取登入頁覆蓋。离線 App 可讀已存本機資料，不代表離線重新驗證帳號。

## 版面與裝置

| 情境 | 預期 |
|---|---|
| iPhone 直式／橫式 | 紙張完整可見，選角準確，工具可以捲動 |
| iPad Safari／主畫面 | 同樣工作流程；大畫面工具不妨礙紙面 |
| 專注畫面 | 相機區域填滿可用 viewport；「工具」可開關面板；可退出 |
| Fullscreen API 不支援／被拒絕 | 專注版面仍可使用，不中斷 Session |
| Wake Lock 支援 | 提示描圖中保持亮起；離開頁面釋放 |
| 低電量／不支援 Wake Lock | 不假稱成功；仍能保存與重新對位 |
| 權限拒絕／相機被占用 | 可理解提示；模擬模式仍可用 |
| 休眠／切 App | 相機停止；恢復需要重新開啟與選角，paper transform 不變 |
| 旋轉裝置 | 重新校準，圖片比例與紙上位置仍保留 |
| viewport resize／工具顯隱 | 只重算顯示，不重設紙上構圖 |
| 大照片／EXIF／HEIC | 正確方向或明確錯誤提示，頁面不殘留舊圖片 |

首次沒有完整離線快取、網站資料被清除、儲存被回收時，需要重新連線。外部登入是線上流程，不能當作已驗證的離線功能。若私密部署阻擋 service worker，需要修部署或另外選部署方案，再測；不能直接把 Site 改成公開。
