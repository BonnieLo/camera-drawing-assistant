# M2 — 參考圖與紙上編輯驗收

此清單驗收 M2 的參考編輯功能。M3/M4 現已加入保存／恢復與 PWA，請一起參考對應清單及 TEST_STATUS.md。實際 Safari 相機、照片解碼、CSS 透視與雙指操作尚未驗證。M1 的相機/校準實機清單仍須一起驗收。

## 快速體驗（不必授權相機）

1. 在 Safari 開啟測試網址，選「02 參考圖片」→「試用花瓶範例」。
2. 回到「01 紙張校準」→「開始選角」，依畫紙的 A 左上、B 右上、C 右下、D 左下選四角。
3. 確認校準後應看見半透明花瓶疊在紙面。單指移動，雙指縮放、旋轉。
4. 調整透明度、寬度及旋轉 slider；微調箭頭每次移動相對紙邊的 1%。
5. 鎖定後拖曳不應改變圖片，但透明度與暫時隱藏仍可使用。
6. 切換模擬角度後，參考圖會暫時隱藏；重新選四角並確認，花瓶應回到相同紙上構圖。寬度、旋轉、透明度與鎖定狀態不得重設。

## 真實畫紙

建議先選照片，再開相機並校準。iOS 照片選擇器若讓頁面進入背景，相機會停止並要求重新校準，避免沿用可能失效的對位。

| 項目 | 預期 |
|---|---|
| 照片匯入 | JPEG/PNG 可顯示，直式照片方向正確；無法解碼的格式顯示提示 |
| 大照片 | 保持長寬比，長邊最多 2048 px；照片由瀏覽器本機處理，沒有上傳 API |
| 斜角紙面 | 圖片整體透視與紙張一致，不只是四邊形外框正確 |
| A4 上旋轉 | 花瓶或人像在旋轉 90° 後形狀比例一致，沒有額外拉長 |
| 單指 | 在纸面拖曳時移動參考圖，畫面不捲動；工具區仍可捲動 |
| 雙指 | 同時縮放與旋轉，抬起一指後沒有跳位，可以繼續單指移動 |
| 鎖定 | 移動、尺寸、旋轉 disabled；opacity / hide / re-align 仍可用 |
| 裁切 | Reference 超出紙面部分隱藏，相機畫面仍完整顯示 |
| 專注版面 | 切換版面不重設校準；它是 viewport layout，不是相機 pose |
| 改變相機角度 | 手動重新校準後，原 reference paper transform 保留 |
| 切 App / 休眠 | 未重新載入頁面時保留記憶體中的參考圖，重新開相機与校準；Safari 若回收頁面，從 M3 已保存的 Session 恢復；未保存變更可能消失 |
| 移除或更換圖片 | 舊預覽不殘留；更換圖片以置中構圖開始 |

## M2 功能本身的範圍（保存與 PWA 另見 M3/M4）

- 未保存的構圖仍可能在重新整理、關閉或系統回收頁面後消失；M3 已提供 Save / Resume，請確認「已保存」。
- M4 已提供 PWA 安裝/離線程式，實機相容性待測；仍沒有持續自動追蹤紙張。
- 手動校準後仍需固定相機。Reference Lock 不是世界追蹤。
- HEIC 解碼依 Safari 支援而定，失敗時改用 JPEG/PNG；本環境沒有用真實 iPhone HEIC 完成驗證。
- 四角需要完整可見。彎曲紙面與鏡頭畸變可能造成紙張內部誤差。

請記錄裝置、OS、步驟、預期/實際、可否重現。iPhone 與 iPad 分別記錄；沒有測過的裝置標為 NOT TESTED。
