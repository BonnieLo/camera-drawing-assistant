# M3 — Session 保存與恢復

狀態：實作與自動回歸通過；iPhone / iPad **NOT TESTED**。

## 保存 → 關頁 → 換相機角度 → 恢復

1. 使用實體 A4 紙。A 角作小標記，手機固定，匯入照片並校準四角。
2. 移動至不在中央的位置，寬度例如 46%、旋轉 32°、透明度 30%，鎖定。描出三個可辨識特徵。
3. 到「我的作品」命名並保存，等待「已保存」。匯出 `.paper.json` 到「檔案」，確認檔案存在。
4. 關閉分頁，重新開啟同一網址；選作品、按恢復。圖片應已載入，但不得直接疊加為已校準。
5. 改變手機距離和斜角。重新開相機，指定同一實體 A–D 四角並確認。
6. 原位置、紙上大小、旋轉、透明度、鎖定應保留；三個特徵應貼合原畫線。誤差記錄照片與選角，勿宣稱毫米精度。
7. 休眠、切 App、裝置旋轉後重复；相機必須停止或校準失效。重新對位後構圖不得重設。

## 自動保存與操作

| 測試 | 預期 |
|---|---|
| 未首次保存便編輯 | 提醒未保存；不悄悄建立專案 |
| 首次保存後調整 | 停止操作約 750 ms 後保存；顯示完成或明確失敗 |
| 寫入中再調整 | 新變更仍標記未保存，再次保存最新狀態 |
| 專案改名 | 同 Session 更新名稱與修改時間 |
| 另存新作品 | 新 ID；原 Session 保留 |
| 恢復其他作品 | 有未保存內容時嘗試保存／確認放棄，不能靜默丟棄 |
| 移除參考圖 | 不刪除已保存 Session；開始新作品或更換照片 |
| 刪除作品 | 明確確認；畫面中的構圖不連帶消失 |
| 匯出再匯入 | 圖片／構圖／紙張設定相同，匯入建立新 ID，不覆蓋原作品 |
| 損壞／其他 JSON／未支援版本 | 提示失敗，原構圖與原 Session 不變 |
| 圖片無法解碼／尺寸不符 | 拒絕恢復，原构圖不變 |
| quota／禁止儲存／私密瀏覽 | 不顯示成功；可匯出當前構圖備份 |

資料只在本站的當前瀏覽器／主畫面儲存。清除網站資料可能使其遺失。不要以 unload 保存作為保障；離開前確認完成並匯出重要作品。多個分頁同時編輯同一 Session 目前採最後寫入，不提供衝突合併。
